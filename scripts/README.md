## 工具脚本

### `embed_luxe.py` —— 图片内嵌

把 HTML 里的 `__IMG_xxx__` 占位符替换成 base64。

```bash
python embed_luxe.py
```

**什么时候用：**

- 给页面加了新图
- 从 `frontend/images/` 批量内嵌到 HTML

**注意：** 只有部分页面需要内嵌（首页、购物袋、售后）。商城和商品详情是从 API 动态加载图片的，不需要内嵌。
