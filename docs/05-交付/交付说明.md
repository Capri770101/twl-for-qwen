## 二、三步跑起来（约 15 分钟）

### 前置条件

| 软件 | 版本 | 说明 |
|---|---|---|
| Python | **3.11** | 不要用 3.12+，部分依赖未适配 |
| PostgreSQL | **18** | 需要先建好数据库，且知道密码 |
| Windows | 10 / 11 | `启动.bat` 只在 Windows 下可用 |

### 第 1 步：建库 + 配 .env

```bash
# 建数据库（在 psql 或 pgAdmin 里执行）
CREATE DATABASE tiaowulan;
```

复制配置模板并编辑：

```powershell
cd backend
copy .env.example .env
```

`.env` 里**必须填**的只有这几项：

```ini
POSTGRES_HOST=127.0.0.1
POSTGRES_PORT=5432
POSTGRES_USER=postgres
POSTGRES_PASSWORD=你的数据库密码          # ← 必改
POSTGRES_DB=tiaowulan
SECRET_KEY=随便一串至少32位的字符          # ← 必改，上线前务必换成随机串
```

### 第 2 步：装依赖 + 建表

```powershell
cd backend
python -m venv .venv

# 只跑服务（最小安装）
.venv\Scripts\pip install -e .

# 要跑测试 / 验收 —— 推荐用这条，多装 pytest
.venv\Scripts\pip install -e ".[dev]"

.venv\Scripts\alembic upgrade head
```

> **注意** `pip install -e .` **不会**安装 pytest，测试脚本会报 `No module named pytest`。验收必须用 `".[dev]"`。
> **注意** Windows 上 `colorama` 是 structlog 彩色日志的硬依赖，已在 `pyproject.toml` 里声明为 Windows 条件依赖，正常安装会自动带上。如果 `import app.main` 报 `SystemError: ConsoleRenderer with colors=True ... requires the colorama package`，单独 `pip install colorama` 即可。

### 第 3 步：灌初始数据（**顺序不能乱**）

```powershell
# ① 灌 8 个示例商品（幂等，重复跑只更新不重复插入）
.venv\Scripts\python.exe scripts\seed.py

# ② 导入 15 篇花语/养护/场景文章
cd ..\scripts
..\backend\.venv\Scripts\python.exe import_content.py

# ③ 回项目根目录，双击启动
cd ..
.\启动.bat
```

浏览器打开 **http://127.0.0.1:8000/** 能看到首页就成功了。

> **为什么顺序不能乱**：`seed.py` 和 `import_content.py` 都要求表已存在（第 2 步的 `alembic upgrade head`），而启动器只负责起服务、不负责建表。

## 三、后台账号怎么进

**这个系统没有密码，登录 = 手机号 + 6 位验证码。**

| 环节 | 说明 |
|---|---|
| 进后台 | http://127.0.0.1:8000/admin.html |
| 取验证码 | 开发环境点「获取验证码」，后端直接把码返回并**自动填入输入框**（不发真短信） |
| 设管理员 | 用你的手机号登录一次（会自动建用户），然后执行下面任一条 |

**方式 A（推荐，写进数据库）：**

```sql
UPDATE users SET is_admin = TRUE WHERE phone = '你的手机号';
```

**方式 B（临时，写进 .env）：**

```ini
ADMIN_PHONES=你的手机号
```

> ⚠ 方式 B 配完记得清空，否则任何人填这个号都是管理员。
> 生产环境启动时会强制校验 `ADMIN_PHONES` 必须为空，配了会拒绝启动。

## 八、已知限制（诚实版）

| 项 | 现状 | 影响 |
|---|---|---|
| **支付** | Mock，模拟收银台 | **收不了真钱**，必须接微信支付 |
| **短信** | Mock，验证码回填输入框 | 上线必须接阿里云/腾讯云短信 |
| **文件存储** | 本地磁盘 `backend/storage/uploads/` | 多机部署必须换 OSS |
| **缓存** | 进程内存 | 验证码重启即丢，多进程不共享，生产必须换 Redis |
| **商品/配送/联系方式** | 全是示例数据 | 老板接手后必须替换 |
| **内容** | 15 篇（目标 75 篇） | 可继续写，导入脚本已就绪 |
| **ICP 备案** | 未办 | **7–20 天，所有上线工作的前置，尽早开始** |
| **移动端真机** | 只在 headless Chrome 验证过 | 建议上线前用真机过一遍 |

生产环境启动时会**自动校验**以下项，不合规直接拒绝启动：

```ini
APP_ENV=production
DEBUG=false
SECRET_KEY=              # ≥32 位随机串
CORS_ORIGINS=            # 不能含 *
CACHE_PROVIDER=redis
SMS_PROVIDER=            # 不能是 mock
STORAGE_PROVIDER=        # 不能是 local
PAYMENT_PROVIDER=        # 不能是 mock
ADMIN_PHONES=            # 必须清空
```
