## frontmatter 字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `slug` | ✅ | URL 里的英文名，全小写，用连字符。**决定前端 URL** |
| `title` | ✅ | 文章标题，包含核心关键词，≤30 字 |
| `category` | ✅ | 分类：rose / tulip / sunflower / hydrangea / carnation / lily / guide / care |
| `meaning` | ✅ | 花语一句话，显示在列表页 |
| `cover` | 建议 | 封面图，用 `/images/xxx.webp` |
| `tags` | 建议 | 标签数组，用于关联推荐 |
| `status` | ✅ | `published`（发布）/ `draft`（草稿） |
| `sort_weight` | 否 | 排序权重，数字越大越靠前 |
| `seo_title` | 建议 | SEO 标题，可以和 title 不同 |
| `seo_description` | 建议 | SEO 描述，50–160 字 |

## 写作要求（五条硬标准）

### ① 开头必须有一句话答案

**为什么：** AI 引用你的内容时，最可能引用的就是开头这一句。

**好：**
```markdown
白玫瑰的花语是**纯洁、天真与尊敬**。在婚礼上它代表祝福...
```

**不好：**
```markdown
玫瑰花是很多人喜欢的花。白玫瑰作为一种特殊的玫瑰...
（绕了 100 字才说花语是什么）
```

### ② 每篇 800–1800 字

太短没内容，太长读者看不完。

### ③ 必须有具体数字

| 好 | 不好 |
|---|---|
| 「深圳同城 2 小时达，16:00 前下单当日送达」 | 「很快送达」 |
| 「含保鲜剂常温可养 5–7 天」 | 「能养挺久」 |
| 「斜剪根部 1–2cm」 | 「剪一下根」 |
| 「500ml 水配 1 包保鲜剂」 | 「按比例兑」 |

### ④ 结尾 3–5 个 FAQ

用 `### 问题？` 的格式，脚本会自动提取成 `FAQPage` 结构化数据。

**FAQ 怎么找：**
- 客服真实遇到的问题
- 百度「相关搜索」
- 小红书评论区的提问

### ⑤ 末尾加内链

链接到相关文章和商品列表页，形成内容网络。

```markdown
## 你可能还想知道

- [香槟玫瑰的花语是什么](/flower-language-detail.html?slug=champagne-rose)
- [全部花语百科](/flower-language.html)
```

## ⚠ 准确性说明（重要）

**现有的 15 篇内容来自 AI 的训练数据，没有逐条联网核实。**

**这意味着：里面写的是「广泛流传的说法」，不是「查证过某个权威来源」。**

### 已知有问题的 4 处

| 文件 | 问题 | 建议 |
|---|---|---|
| `champagne-rose.md` | 「爱上你是我今生最大的幸福」不是权威花语，是中文网络流传的说法。维多利亚花语里香槟玫瑰没有独立条目 | 改成「香槟色象征克制与优雅」 |
| `white-tulip.md` | 「白马王子」品种名不确定对应哪个英文品种 | 删掉，只留 Purissima / White Dream |
| `white-tulip.md` | 「失恋」含义有分歧，英文资料有完全相反的 "I am worthy of you" | 标注「不同体系说法不一」 |

**上线前建议人工复核这 4 处。**

## 写作流程

### 1. 选选题

从 `选题清单.md` 里挑，或者从真实客户提问里找。

### 2. 查资料

- 花语：查维多利亚花语体系、中国传统花语
- 养护：园艺常识，可查证
- 数据：用门店真实数据（没有就不写）

### 3. 写初稿

按模板填，**约 40 分钟一篇**。

### 4. 导入

```bash
cd scripts
python import_content.py
```

**输出：**
```
找到 16 个文件
  + 花语\lily.md  新增「百合的花语是什么？为什么不能随便送」（5 个 FAQ）
  ~ 花语\white-rose.md  更新「白玫瑰的花语是什么？和红玫瑰有什么区别」（4 个 FAQ）
新增 1，更新 15，跳过 1
```

### 5. 更新站点文件

```bash
python gen_site_files.py
```

**为什么要跑：** sitemap 和 llms.txt 需要包含新文章。

### 6. 检查

```bash
python audit_seo.py
```

看「内容质量」和「内链」两项是否 100%。

## 解析规则（import_content.py 怎么工作）

**1. frontmatter 解析**
自己写的简易解析器，不引 PyYAML。支持字符串、数组 `[a, b]`、布尔、数字。

**2. FAQ 提取**
从「## 常见问题」下面提取 `### 问题` + 段落，组装成：

```json
[
  {"question": "白玫瑰适合送什么人？", "answer": "适合送新娘、长辈..."},
  {"question": "白玫瑰能养几天？", "answer": "常温下含保鲜剂可养 5-7 天..."}
]
```

**存到数据库的 `faq` 字段（JSONB）**，前端 SSR 时转成 `FAQPage` 结构化数据。

**3. upsert**
按 `slug` 查：
- 有 → 更新
- 没有 → 新增

**所以可以重复跑，不会重复创建。**
